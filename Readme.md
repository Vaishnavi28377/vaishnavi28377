## `03 / THINGS I'VE BEEN BUILDING`

I believe projects are more than lines of code. They're opportunities to experiment, learn from mistakes, and make ideas tangible.

### 🩺 01 — Cancer Prediction with Machine Learning

<kbd>HEALTHCARE AI</kbd> <kbd>CLASSIFICATION</kbd>

Exploring how machine learning algorithms can identify patterns in patient-related datasets and predict cancer-related outcomes.

- Synthetic data generation and preprocessing.
- Feature engineering and model comparison.
- Cross-validation and performance evaluation.
- Classification metrics including precision, recall, F1-score, and ROC-AUC.

**Tools:** Python · Pandas · Scikit-learn · Matplotlib

---

### 🎵 02 — Music Generation with AI

<kbd>GENERATIVE AI</kbd> <kbd>DEEP LEARNING</kbd>

What happens when a machine learns patterns in music? This project explores sequence modelling to generate musical ideas using neural networks.

- Preparing MIDI-based musical sequences.
- Exploring LSTM-based sequence learning.
- Experimenting with model-generated musical patterns.

**Tools:** Python · TensorFlow/Keras · Music21 · PrettyMIDI

---

### 🌱 03 — Agentic Seed Advisor

<kbd>AGENTIC AI</kbd> <kbd>AGRICULTURE</kbd>

**Focus:** AI agents · Agricultural insights · Recommendation workflows
